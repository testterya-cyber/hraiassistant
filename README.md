# 🤖 HR AI Ассистент v2

Умный помощник рекрутера на базе Claude AI. Светлый дизайн, история сессии, без ошибок CORS.

---

## 🚀 Как обновить сайт на Vercel (пошагово)

### Шаг 1 — Удали старые файлы на GitHub
1. Зайди в свой репозиторий на github.com
2. Удали все файлы (можно по одному, нажав на файл → иконка корзины)

### Шаг 2 — Загрузи новые файлы
Загрузи файлы из этого архива в репозиторий:

**В корень репозитория:**
- `package.json`
- `next.config.js`

**Создай папку `pages` и загрузи:**
- `pages/index.js`
- `pages/_app.js`
- `pages/api/claude.js`

**Создай папку `styles` и загрузи:**
- `styles/globals.css`

**Создай папку `components` и загрузи:**
- `components/Landing.js`
- `components/Login.js`
- `components/Assistant.js`

### Шаг 3 — Обнови переменную окружения на Vercel
1. Зайди на vercel.com → твой проект → Settings → Environment Variables
2. Удали старую `VITE_ANTHROPIC_API_KEY`
3. Добавь новую:
   - Name: `ANTHROPIC_API_KEY`
   - Value: твой ключ (тот же)
4. Нажми Save → Redeploy

## 👥 Как добавить клиента

Открой `components/Login.js` и найди:
```js
const USERS = [
  { login: 'client1', password: 'hr2025' },
  ...
```
Добавь строку с новым логином и паролем.

## ❓ Где хранится история?

История хранится в рамках **одной сессии** (пока открыт браузер).
Для постоянного хранения нужна база данных — это следующий шаг развития продукта.
