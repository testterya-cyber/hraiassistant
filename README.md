# 🤖 HR AI Ассистент

## Что умеет
- 📄 Парсинг резюме (PDF или текст)
- 🎯 Составление профиля должности  
- ⭐ Оценка кандидата с вердиктом
- 💬 Генерация вопросов для интервью

---

## 🚀 Запуск на Vercel (5 минут)

### Шаг 1 — Получи API ключ Anthropic
1. Зайди на https://console.anthropic.com
2. Зарегистрируйся, пополни баланс на $10
3. Создай API ключ — скопируй его

### Шаг 2 — Загрузи на GitHub
1. Зайди на https://github.com, создай аккаунт
2. Создай новый репозиторий
3. Загрузи все файлы этой папки

### Шаг 3 — Задеплой на Vercel
1. Зайди на https://vercel.com
2. Нажми "Add New Project", выбери репозиторий
3. Добавь переменные окружения:
   - ANTHROPIC_API_KEY = твой ключ
   - USERS = login1=pass1,login2=pass2
4. Нажми Deploy — получишь рабочую ссылку!

## 👥 Управление клиентами
Добавляй клиентов в USERS через запятую:
USERS=ivanova=pass123,petrova=pass456
